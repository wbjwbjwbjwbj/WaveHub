项目需求：
1、要求能从本地文件系统加载波形数据并处理。
2、支持的波形数据类型包括MiniSeed，cd1.1，wav和用户自定义的波形数据格式。
3、具备台站信息管理功能，能增删改查，并且批量导入导出基础信息，基础信息包括台站及多个传感器坐标，传感器和波形采集设备的关键参数。
4、具备基于正确事件时空参数推算信号到达目标台站的方向角及到达时段的功能。
5、具备数据多维度展示功能，支持波形图与时频图的独立显示，同屏显示，以及时间轴的同步联动控制，联动缩放，具备横向纵向的双轴缩放功能。
6、支持对选定波形数据进行滤波处理，滤波器类型，带宽，加窗类型及FFT窗口参数均可配置。
7、系统集成winPMCC，支持对算法涉及的所有参数进行可视化配置并提供参数的保存，导入与导出功能。
8、WinPMCC计算默认采用全阵元模式，并支持用户手动指定台站组合进行计算。
9、支持winPMCC算法计算过程及结果的可视化，支持用户自定义展示项，使用雷达图显示信息到达台站的时间，方向角，视速度等关键信息。
10、具备信息与检测与测向功能，支持基于台站测向结果进行交叉定位，加载地图并在地图上直观显示台站位置及定位结果
